# MyDay – To-Do List App 📝

A task management web application designed to help users organize their daily activities, manage important tasks, and track their productivity through a clean and intuitive interface.

## ✨ Features

- **Task Management:** Add new tasks with a title, description, and due date.
- **Multiple Views:** Navigate between All Tasks, Important, Planned, and Lists sections.
- **Important Tasks:** Mark tasks as important and access them in a dedicated section.
- **Task Completion:** Mark tasks as completed using checkboxes.
- **Progress Tracking:** Monitor task completion with a dynamic progress indicator.
- **Planned Tasks:** Organize upcoming tasks and manage overdue, daily, and weekly tasks.
- **Interactive Modal:** Open and close the task creation window with intuitive interactions.

## 🛠️ Technologies

- **HTML5** – Semantic structure and page content.
- **CSS3** – Layout, styling, and visual design.
- **JavaScript (ES6+)** – DOM manipulation, event handling, and dynamic interactions.
